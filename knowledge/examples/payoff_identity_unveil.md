# 身份揭露式爽点

长期伏笔的「身份牌」在关键时刻掀开，制造全场震动的情绪爆点。

- 铺垫期：至少给 1-2 处「不寻常细节」做钩子（一句方言、一枚旧信物、一个反常反应）。
- 揭露瞬间：让揭示由「第三方权威」完成（旁观者/对手的师父/当众的档案），比主角自曝更有力。
- 现场反应：围观者要有层次——轻视者的错愕、中立者的敬畏、亲近者的百感交集。
- 后续张力：身份揭露后立刻制造「新期待」（更大的对手/更高的舞台），防止高潮即尾声。

黄金结构：观众早知道、剧中人不知道 → 揭示时爽的是「看他们震惊」；观众和剧中人都不知道 → 揭示时爽的是「原来如此」。
