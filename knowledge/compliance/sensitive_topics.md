# 敏感话题处理

涉及宗教、民族、医疗、未成年人等话题时，用「规避 + 淡化 + 虚构」三原则。

- 宗教民族：不虚构现实宗教经典、不歪曲民族习俗；如需民族元素，只做符号化致敬。
- 医疗保健：涉及治病、用药、保健功效，不得给出具体医疗方案或夸大疗效（易触医疗广告红线）。
- 未成年人：不得出现未成年人涉犯罪、早恋露骨情节、校园暴力正面美化。
- 公职人员/机构：警务、司法情节保持正面或中性，不丑化执法机关。
- 历史人物：已故名人可致敬但不得戏说丑化；当代人物一律不使用真名。

写法建议：拿不准的情节默认「虚构 + 免责声明式淡化」；涉及专业领域（法律/医学）用含糊台词带过，把专业感留给动作与氛围。
